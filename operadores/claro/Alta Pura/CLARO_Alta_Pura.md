# CLARO - ALTA PURA

## 1. Alta Pura

Es el proceso mediante el cual se genera un nuevo número de línea. No es
una línea que migra o se modifica.

### 1.1. Canales de solicitud

La solicitud puede realizarse en:

-   Oficinas Comerciales habilitadas.
-   Call Center.

## 2. Consideraciones Generales

-   La línea se ofrece en paquete (Internet + Movil).
-   Sólo se ofrecen Líneas Control.
-   Sólo se ofrecen Planes Pospagos.
-   No hay requisito de permanencia para telefonía.
-   No se cobra el período que va desde activación al cierre de ciclo
    (no se cobra factura proporcional).
-   Cantidad máxima de líneas por cliente:
    -   **5 para consumidor final** (4 líneas adicionales al paquete).
    -   **15 para comercio o empresas** (14 líneas adicionales al
        paquete).

## 3. Plazo

La demora de los envíos es de **hasta 5 días hábiles**.

## 4. Sondeo comercial

Se debe consultar principalmente el uso que el cliente le dará a la
línea.

### Trabajo

Para vendedores, independientes y fleteros.

-   Necesitan un Plan Control intermedio/alto.
-   Es especialmente importante que incluya WhatsApp gratis con
    llamadas/audios sin gastar datos.

### Estudio

Buscan gigas para:

-   Descargar PDF.
-   Usar Zoom.
-   Usar Classroom.

### Juegos o Streaming

Plan ideal:

-   Plan Control de gama alta en gigas.

### Viaja al exterior

Plan ideal:

-   Plan Control que incluya Roaming Movistar, con gigas y WhatsApp
    gratis en países limítrofes.

### Usuario analógico

Perfil: **solo llamadas / WhatsApp**.

Plan ideal:

-   Plan Control más económico del catálogo, con llamadas libres.

### Perfil familiar

Pregunta orientativa:

> ¿Las líneas de tu casa, las pagás todas juntas vos?

Se puede ofrecer portabilidad de todas las líneas.

## 5. Requisitos

-   Si es o fue Cliente de ISP, deberá tener la Cuenta al día (sin
    deuda).
-   Fotocopia de DNI (ambos lados).
-   El titular de la cuenta deberá firmar el Contrato de Alta para
    solicitar las líneas.

> **Pendiente:** el documento fuente indica que falta disponer del
> contrato.

## 6. Información que deberá proporcionar el usuario

-   Categoría de cliente: Residencial o Comercial.
-   Tipo y número de documento (DNI o CUIT).
-   Información de contacto: Teléfono y Mail.
-   Actualizar mail de Cube.
-   Plan que desea para cada línea.
-   Prefijo interurbano que desea para cada línea.
-   Domicilio de entrega de SIM. Debe ser el mismo que el domicilio de
    facturación de Internet.
-   Mail de recepción del QR para e-SIM.

Referencia para códigos telefónicos:

https://www.argentina.gob.ar/pais/codigo-telefonia

## 7. Oficinas Comerciales y Call Center - Solicitudes

-   Cargan los pedidos en la **Planilla de Gestión de Telefonía**.
-   Envían por mail la documentación del usuario (fotocopias y contrato
    firmado) a la **Isla Especialista**.

> **Pendiente:** el documento fuente indica que la Planilla de Gestión
> de Telefonía falta terminar.

### 8.4. Seguimiento de pedidos

#### Correo Argentino

El Ejecutivo de Cuenta responde el mail enviado por la Isla Especialista
con los números de seguimiento de los chips, que se envían por Correo
Argentino.

La Isla Especialista:

1.  Ingresa a Correo Argentino.
2.  Ingresa el código de seguimiento.
3.  Hace clic en **Consultar**.

Página indicada en el documento fuente:

https://www.correoargentino.com.ar/formularios/ondnc

#### Portal de Autogestión

Ingresar a:

**Portal → Gestiones Móviles → Equipos y SIM → Seguimiento de pedidos**

para verificar si llegaron los chips.

**Si llegaron:**

-   Actualizar el Alias con:
    -   `nro. de clientes de ISP Cube-Nombre del usuario`
-   Ejemplo:
    -   `94765-Pedro Jiménez Pedrera`

**Si no llegaron:**

-   Verificar si se venció el plazo.
-   Si el plazo se venció:
    -   Reclamar desde:
    -   **Portal → Gestiones Móviles → Equipos y SIM → Reclamos de
        envíos**
-   Si el plazo no se venció:
    -   Esperar.

## 8.5. Desbloqueo y activación

Todo envío que va por Correo Argentino llega bloqueado.

Se desbloquea:

-   Desde el Portal.
-   Activando el producto seleccionado desde:
    -   **Portal → Gestiones Móviles → Equipos y SIM → Activación de
        Equipos y SIM**
-   Cuando Correo Argentino informa que el chip fue entregado.

## 8.6. Actualización del Alias

La línea aparecerá a nombre de ISP.

Para modificar el usuario:

**Portal → Gestiones Móviles → Líneas Móviles → Cambio de usuario**

Utilizar:

`id Cliente-ApyNom usuario`

Si el usuario tiene varias líneas a su nombre, indicar:

``` text
id Cliente-ApyNom usuario 1
id Cliente-ApyNom usuario 2
```

Además:

-   Actualizar el estado del trámite en la **Planilla de Gestiones de
    Telefonía**.
-   Informar a Stock el receptor y domicilio de envío de los chips.

## 9. Acción del Usuario

Cuando el usuario recibe el chip:

1.  Debe colocarlo en el equipo.
2.  Debe esperar unos minutos hasta recibir el SMS de activación.
3.  A partir de ese momento la línea queda operativa.
